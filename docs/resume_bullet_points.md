# Resume Bullet Points

## Versao Curta
Desenvolvimento de dashboard em Power BI para gestão de portfólio de projetos elétricos, integrando indicadores de prazo, potência, status, custos, responsáveis, pendências e desempenho operacional.

## Versao ATS
Desenvolvi um dashboard de Business Intelligence em Power BI para gestão de projetos de engenharia elétrica, utilizando Python para geração e validação de base sintética, modelo estrela, medidas DAX, indicadores de prazo, potência em kW/MW, valor de carteira, pendências, carga de trabalho e performance operacional.

## English Version
Built a Power BI portfolio dashboard for electrical engineering projects, combining Python-generated synthetic data, star-schema modeling, DAX measures, schedule KPIs, power capacity, portfolio value, owner workload, pending issues and operational performance analysis.
